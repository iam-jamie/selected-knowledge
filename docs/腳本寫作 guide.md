# 腳本寫作指南(去 AI 味檢查清單)

在開始寫腳本之前,請先讀完這份指南,並在寫作全程遵守。

## 基本格式規則

- 全程使用繁體中文,不可出現簡體字
- 第二人稱「你」直接對話語氣,像在描述觀眾本人正在經歷的事
- 不使用第三人稱角色或虛構人名(例如「他們」「阿翔」「小美」)
- 只輸出乾淨的口白文字,不要有章節標籤、時間戳記、結構標記
- 需要的結構或製作備註,另外附在腳本之外,不要混進口白裡

## 避免的 AI 寫作痕跡

### 詞彙與語氣
- 誇張的象徵意義或歷史定位詞:「標誌著」「見證了」
- 廣告/宣傳語氣:「充滿活力的」「令人嘆為觀止的」
- 空泛的「-ing」式分析尾巴
- 模糊的權威歸因,沒有真實來源:「專家認為」「有觀察者指出」
- 制式的「挑戰與未來展望」段落
- 濫用的 AI 常見詞彙:此外、至關重要、展示、格局、賦能、豐富的⋯⋯
- 用繞口說法系統性迴避「是」
- 客服式收尾:「希望這對您有幫助!」「當然!」
- AI 知識截止免責聲明
- 諂媚語氣、填充詞、過度保留(hedging)
- 空泛通用的正面結論

### 句型結構
- 否定對照句:「不僅是⋯⋯而是⋯⋯」「不是 A,而是/更像是 B」
- 硬湊三件事的三段式列點
- 用同義詞輪替來迴避重複用字
- 假範圍修辭:「從⋯⋯到⋯⋯」
- 破折號(—)過度使用,單集控制在1~2次以內
- 機械式加粗、行內粗體條列清單
- emoji 裝飾

### 段落/整集層級(容易被忽略,但多集累積後很明顯)
- **固定收尾模板重複使用**:例如「我自己覺得最⋯⋯的地方是⋯⋯而現在,AI 已經/都可以⋯⋯你覺得⋯⋯?」不同集數不要套用同一句型,要嘛換句型,要嘛拿掉這種「AI 收尾」的固定梗
- **固定轉折句重複使用**:例如「等等——所以⋯⋯?」這類「破折號+反問」組合,同一系列多集出現會顯得可預測,需要換說法
- 這兩點必須跨集檢查,不是只看單一集本身

## 正面做法(該做的事)

- 句子長短交錯,節奏要變化,不要每句都差不多長
- 相信讀者,直接陳述事實,不用鋪墊
- 適度注入真實觀點、第一人稱反應
- 允許一點「不整齊」——旁枝、隨性的語氣
- 用具體細節取代空泛說法
  - 如果是權威人士說的或者史實，請直接用那個專有名詞


### 避免敘事模板化

#### ** 開頭 Hook**
- Hook 放在影片最前面 3-8 秒,最晚不要超过 15 秒。8-12 分鐘影片是中長片,觀眾滑到就是要在幾秒內判斷「這個值不值得我花 10 分鐘」。
- Hook 結構(3 個要素,依序疊加):
  - 開場第一句(0-3 秒):拋出結果/衝突/反常識的一句話：不要鋪陳、不要自我介紹、不要「大家好我是XX」。直接丟出全片最有張力的資訊或問題。
例如(以你「好奇查理」頻道風格為例):「你每天過馬路等紅綠燈,但你知道紅綠燈其實是為了解決一場馬車車禍才發明的嗎?」
  - 利害關係(3-8 秒):告訴觀眾「這跟你有什麼關係」：把主題連到觀眾自己的生活經驗,製造「這件事我每天都在做,但我從來沒想過」的認知落差。
  - 承諾(8-15 秒):暗示影片會給出什麼答案,但不要爆雷：一句話說「接下來我會告訴你」,製造懸念,讓觀眾決定留下來看完。
- 常見錯誤(避免):
  - 頻道 Logo / 音樂 intro 放在 hook 前面 → 直接刪掉或移到 hook 之後
  - 先講「今天要跟大家聊聊 XX 主題」→ 這是资讯,不是 hook,觀眾聽了就划走
  - Hook 講太多細節、把答案講一半 → 沒有懸念,觀眾覺得聽完精華就可以走了

#### Re-hook
  - 8-12 分鐘影片建議在 4-6 分鐘處(中段)安插至少一次 re-hook,YouTube 的 retention 曲線通常在這個位置開始明顯下滑。
  - Re-hook 的 3 種寫法(挑 1-2 種用,不用全部塞):
    1. 預告轉折/反差:「但這個說法後來被推翻了,真正的原因跟你想的完全不一樣」
用途:當影片要從「現象」轉到「原因」或「反常識解釋」時使用
    2. 拋出下一層問題:「那你有沒有想過,為什麼這個規則到現在還沒有被淘汰?」
用途:當影片內容還有第二層更深的懸念時使用
    3. 利害關係加碼: 「而這件事其實不只影響你怎麼看紅綠燈,它還跟你每天做的另一件事有關」。用途:把觀眾原本以為「已經聽完重點」的鬆懈感打斷,製造新的留下理由
  - 放置原則:
    - 抓在「一個小結論講完、準備進入下一段落」的銜接點,不要硬插在句子中間
    - 語氣要像自然的話鋒一轉,不要用「好,那我們進入下一個重點」這種結構化用語(會打斷沉浸感)
    - 一支 8-12 分鐘影片最多 1-2 次 re-hook,太多次觀眾會覺得在被操弄


#### **敘事骨架輪替**
- 依主題性質輪流以下敘事骨架。
  - 反直覺揭密型 — 你以為這是人類一直以來的生活方式 → 揭露真相(其實只有 100-200 年歷史/是某個人發明的) → 這代表什麼(現代生活的哪些部分其實是可以被質疑的)。這是最貼合你資料裡「蛤?對欸,我從來沒想過」這個核心 Hook 的骨架,適合「為什麼朝九晚五」「為什麼有週末」這類題目。
  - 起源追溯型 — 從現況切入(你每天都在做這件事) → 追溯到最初的發明者/事件/轉折點 → 對比今昔,點出這件事其實是被設計出來的。適合「第一間公司」「誰發明銀行」「第一個打卡上班的人」這類「起源考古」題目。
  - 制度演化型 — 現況描述 → 中間經歷了哪些關鍵轉折(從 A 走到 B 發生了什麼) → 延伸到現在或未來可能的變化。適合「人類為什麼放棄狩獵採集」「為什麼城市會出現」這類需要交代演變過程的題目。
  - 系統關聯型 — 從一個具體、貼身的小現象切入(你每天做的一件小事) → 拉到背後更大的系統性因素(資本主義/國家制度/經濟結構) → 回扣到「這如何影響你現在的生活」。適合把「為什麼要繳稅」連結到「政府權力從哪裡來」這種由小見大的題目。
- 列出你常用的3種骨架,標記使用頻率
- 超過連續3支同骨架時,強制換一種
- 案例型主題用敘事骨架,概念型主題用對比/拆解骨架

#### **開場結尾去公式化**
- 這5種不同的開場鉤子(懸念/提問/反差/數據/情境代入),隨機/依主題選用
- 結尾避免固定的「所以...記得訂閱」套路句型
- 每支影片開場的第一句話,直接針對該主題的具體內容,不要用通用萬用句

#### **建立你自己的觀點框架**
- 寫作的時候記得頻道的 IP 人設
  - 頻道 IP 人設：我一個充滿好奇心，剛出社會工作沒多久，想了解這個世界/ 社會是如何運作的年輕男性。個性有點樂觀開朗，喜歡梳理並簡化複雜的事物，然後用幽默詼諧的語氣說出故事。
- 每支影片寫作前先問自己:「我對這件事的獨特看法是什麼?」
- 腳本必須是第一人稱視角。使用頻道 IP 人設跟語氣講故事, 並適時加入自己的生活經驗或感受。
- 刻意加入一段「這是我認為最有共鳴的部分」之類的個人觀點段落
- 避免純粹資訊彙整式的腳本(像是把維基百科重新排列)

#### **混合內容類型**
- 依照主題，使用各種不同的內容類型
  - 案例分析型、迷思破解型、問答型、清單型等不同格式擇一使用

### Rule that should follow
  - 使用 “台灣用語” 而不是中國用語
  - 數字請寫中文而不是阿拉伯數字。e.g: 30 請寫三十
  - 如果有英文名詞不用寫在括號裡面 eg. 「芭絲特」（Bastet） 直接寫 「芭絲特」就好，不需要括號英文
  - 腳本中不用寫段落標題
  - 腳本中不用寫場景描述
