# VISUAL STYLE PROFILE

- 視覺風格主要屬於「清晰線條」（Ligne Claire）風格，這種風格深受經典歐洲漫畫（如艾爾吉的《丁丁歷險記》）影響。   其主要核心特點包括：清晰且粗細一致的黑輪廓線：畫面中的人物與物件都帶有乾淨、俐落的黑色描邊，線條感非常突出。   平塗色彩與極簡陰影：色彩呈現上多採用大面積的單色平塗（Flat Color），不使用過多的漸層或複雜光影，給人一種溫馨、復古且帶有插畫感的視覺體驗。   造型簡化與表現力：人物的五官與肢體線條經過高度簡化，但同時保留了生動的動態與情緒表達。
