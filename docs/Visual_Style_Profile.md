# VISUAL STYLE PROFILE（白底版）

## 風格定位

清晰線條（Ligne Claire），歐洲經典漫畫的畫法。整支影片所有分鏡都用同一套規則。背景預設純白，只有顏色本身帶有意義時才上背景色。

## 核心規則

1. **黑色輪廓線**：所有人物和物件都用乾淨、粗細一致的黑線描邊。
2. **平塗色彩**：每個色塊填單一顏色，不用漸層，不畫複雜光影，陰影降到最低。
3. **背景預設純白**：背景預設是純白 `#FFFFFF`。背景色沒有傳達資訊時一律留白，不為了填滿畫面而加色。只有背景色本身有意義時才保留（見下一節）。
4. **造型簡化**：五官和肢體高度簡化，靠眉毛、嘴型和肢體動作表現情緒。
5. **一個視覺焦點**：每張圖只放一個主體，畫大一點，周圍留白，縮小也看得清楚。

## 背景與場景的處理

**判斷標準：這個背景色拿掉之後，觀眾會不會少看懂一件事？** 會，就保留。不會，就留白。

**保留背景色的情況**
- 表示時間：夜晚用深色背景（例如 `#283593`、`#1A237E`），黃昏用暖色。
- 表示環境氛圍：夜間書桌的檯燈光、劇院或博物館的聚光燈，前提是這些光線本身就是畫面要傳達的內容。
- 表示天氣或場域：戶外的天空、沙漠、海面等，而且畫面的重點就是那個環境。

**留白的情況**
- 純粹的物件、符號、示意圖，例如積木階梯、日曆、時間軸、放大鏡、沙漏、靶心。
- 室內場景，但牆面和地板沒有特別意義，例如單純坐在書桌前打字。
- 背景色只是為了「看起來比較滿」。

**畫法**
- 需要交代場景時，只畫場景裡的物件本身，不畫整個房間。
- 需要地面或桌面時，用一條細黑線帶過，不填色。
- 保留背景色時，用單一平塗色塊，不用漸層。一張圖最多一種背景色。

## 固定角色

短黑髮、穿海軍藍毛衣（`#1565C0`）的年輕女子。全片每一格長相、髮型、毛衣顏色都一致，不新增其他角色。畫面裡只出現手、背影或局部時，也維持同樣的毛衣顏色和髮色。

## 抽象概念的畫法

沒有具體畫面的句子，用符號或圖表表現，不硬畫寫實場景。常用的有：紅色 ✕、綠色勾、問號、燈泡、時間軸、箭頭、天平、沙漏、放大鏡、靶心。

## 給 image prompt 用的固定英文句子

**風格句尾**（每一行 prompt 都原封不動貼在最後）：

```
Ligne Claire comic style, uniform clean black outlines, flat color fills, minimal shading, no gradients, retro European illustration
```

**背景句**（接在風格句尾後面，二選一）：

預設，大部分分鏡用這句：

```
, plain pure white background.
```

背景色有意義時（例如夜晚），改用這句，色號和描述依場景調整：

```
, flat dark blue (#283593) night background with a small moon and stars.
```

**主角描述**（畫面有主角時使用）：

```
a young woman with short black hair in a navy (#1565C0) sweater
```

## 寫 prompt 時的提醒

- 先判斷這個分鏡的背景色有沒有意義，沒有就用白底句，有就用背景色句。
- 白底的分鏡，prompt 裡不要出現天空色、牆面色的色號，色號只給物件和符號。
- 提到場景時只寫物件，例如 "a desk with a laptop"，不寫 "in a cozy room"。
- 每一行 prompt 都要帶完整風格句尾加背景句，因為每行會獨立丟進圖像工具。
